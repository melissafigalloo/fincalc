# UI Coding Standards

## Component Rules

- **Use shadcn/ui components only.** All UI components must be shadcn/ui components.
- **No custom components.** Do not create custom/bespoke UI components.
- **Check the registry.** If no suitable shadcn/ui component is currently installed in this app, check the [shadcn/ui registry](https://ui.shadcn.com) for an appropriate component and install it.
